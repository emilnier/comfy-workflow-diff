# ComfyUI 工作流对比器 · v1.3

不依赖 ComfyUI 服务端、完全在本地运行的图形界面小工具。把 **A 当前工作流** 和 **B 目标工作流**（或两张带元数据的成品图）拖进来，它不只列差异，而是直接告诉你：

- 要复制 B 的哪些值；
- 要把哪个节点改为 Bypass；
- 要启用哪个节点；
- 哪些节点是 B 新增 / 仅 A 存在。

工作流图默认**只看变更、不显示连线**；缩小时用固定屏幕尺寸的操作标签和节点名标出目标节点，不再依赖缩成一条线的虚线边框。

全部解析都在浏览器本地完成，不上传任何文件。

## 快速开始

1. 双击 `start-comfy-diff.cmd`。它会用本机 Chrome / Edge 打开一个独立应用窗口。
2. 也可以直接双击 `index.html`，在浏览器里使用。
3. 把当前工作流拖到左侧 **A 当前**，目标工作流拖到 **B 目标**；一次拖两个文件会自动分配。
4. 默认只显示实际变更节点，且不显示连线。点击左侧节点、图中节点或固定尺寸操作标签，右侧会弹出操作详情，左侧列表也会自动跳到对应节点。

> 推荐 Chrome / Edge。浏览器需要支持 `DecompressionStream`（用于解压 PNG 的 zTXt / iTXt 元数据），近几年的现代浏览器都支持。

## 支持的输入

| 输入 | 说明 |
| --- | --- |
| ComfyUI UI 工作流 `.json` | 有 `nodes`、`links`、`groups`，保留节点坐标和组，能画出原布局。 |
| ComfyUI API Prompt `.json` | 只有 `class_type` / `inputs`，没有坐标；会按依赖关系自动排成粗略图。 |
| ComfyUI 原生 PNG | 标准 SaveImage 会把 `workflow` 和 `prompt` 写进 PNG 文本块，可还原节点布局。 |
| Image Saver PNG | 额外支持 `parameters`（A1111 格式）；有 `workflow` 时优先用完整工作流。 |
| Image Saver JPEG / WebP | 支持 EXIF `Make` / `Model` 中的 `workflow:` / `prompt:`，以及 `UserComment` 中的 A1111 参数。 |
| A1111 参数图 | 只有 `parameters` 文本时，会生成「模型 / 提示词 / 采样参数 / 尺寸」摘要图。 |
| 混合比较 | 一侧完整工作流、另一侧只有 A1111 参数时，自动切换成摘要比较，并明确提示。 |

元数据读取覆盖了 PNG `tEXt` / `zTXt` / `iTXt`，JPEG APP1 EXIF / XMP，WebP EXIF / XMP。种子等大整数使用精确解析，不会出现 JavaScript 浮点精度导致的假差异。

## 比较规则

- **节点对应**：优先按节点 ID 配对；如果两边 ID 重合度很低，再按「类型 + 节点标题」做唯一匹配，避免重编号后全部显示成新增/删除。
- **参数名**：优先使用新版 ComfyUI 写出的 `widgets_values_named`；老工作流则按控件输入名回退，并单独处理 `control_after_generate`。
- **显示名称**：优先使用你在 ComfyUI 中起的节点标题，其次使用节点类型（内置常用节点有中文名），并显示所在组名。数字 ID 只作为辅助信息。
- **A→B 操作分类**：每个变化节点自动归类为：
  - `复制 B 参数`：状态相同，仅参数不同；
  - `改为 Bypass`：A 正常/启用，B 为 Bypass；
  - `启用`：A 为 Bypass/静音，B 正常；
  - `状态`：其他模式变化；
  - `新增`：仅 B 存在；
  - `删除`：仅 A 存在。
- **B 目标**：所有复制按钮、目标值和操作卡都以 B 为目标，界面统一显示「A 当前 → B 目标」。
- **节点组**：优先取节点左上角所在的组；重叠组取面积最小的那个，避免把跨组大节点分错。
- **子图**：会展开子图定义，比较内部节点参数和状态，并在子图实例节点上标出，例如：
  `子图 Film Grain / Grain amount · 值`。
- **忽略的噪音**：节点位置、颜色、折叠状态、`Image Comparer` 的临时预览 URL、控件自动补全缓存等，不会算作参数差异。提示词等长文本仍会完整比较。
- **长文本**：差异列表显示截断预览；详情面板显示全文，并对提示词做分段增删高亮。

## 界面

- **A 当前 / B 目标来源卡**：支持拖放、文件选择、清空、交换；全屏拖放提示会在松手、离开窗口或 4 秒后自动消失，`Esc` 也能关闭。
- **A→B 操作摘要**：顶部显示 `9 个节点待处理`、`复制 6（9 项）`、`1 个改为 Bypass`、`1 个新增`、`1 个删除`；点击任一计数即可筛选。
- **复制待办**：一键复制整份操作清单，包含每个节点要复制哪些 B 值、哪些节点改 Bypass/启用。
- **差异列表**：按组 → 节点标题显示，节点头直接给出 `复制 3 / BYPASS / 启用` 操作标签；每个参数行右侧有复制 B 值按钮。点击图上的节点会自动清除会挡住它的筛选并滚动到左侧对应节点。
- **工作流图（默认状态）**：
  - **只看变更** 默认开启，未变化节点隐藏，保留组框与空间位置；
  - **连线** 默认关闭；
  - 自动缩放到所有变更节点；
  - 缩小时每个变化节点显示固定屏幕尺寸的 **操作标签 + 节点名**：
    `复制 3 / Input Parameters`、`BYPASS / KSampler`、`启用 / …`、`新增`、`删除`；
  - 操作标签使用图标、文字、颜色和纹理冗余编码，不依赖细边框；
  - 节点本身使用整块颜色/纹理：复制=琥珀点阵，Bypass=紫色斜纹，启用=绿色点阵，状态=蓝色斜纹；
  - 有变更的组在组标题旁显示固定尺寸汇总 `⧉4 ⊘1`，点击可缩放到该组；
  - 点击任意节点/标签会放大定位、打开右侧操作卡，并自动选中第一条差异。
- **节点详情**：
  - 顶部显示明确操作卡，例如「把该节点改为 Bypass」「复制 B 的 3 个参数」；
  - 显示 `A 当前 → B 目标` 状态；
  - 「待执行操作 / 全部参数」两个视图；
  - 每个参数标题旁、A/B 值框右上角、全部参数表行尾都有 **一键复制**；底部还有 **复制全部 B 值**。
- **导出报告**：顶部「导出报告」下载 Markdown，按组和节点名称组织，并包含 A→B 操作摘要。
- **快捷键**：`0` 适应当前视图，`+` / `-` 缩放，`Esc` 关闭详情，`Ctrl + 滚轮` 缩放。

## 常见问题

### 为什么拖入图片提示找不到元数据？

聊天软件、截图、部分图床和「图片压缩」会移除 PNG 文本块或 EXIF。请使用 ComfyUI 直接输出、未经转存的原始文件。本工具不能从像素反推工作流。

### JPEG 为什么没有完整节点图，只剩 A1111 摘要？

JPEG 的 EXIF 段有 64 KB 左右的上限。Image Saver 遇到超大工作流时会省略 workflow 或 prompt，只保留 A1111 `parameters`。想要完整节点图，请保存 PNG；或者在 Image Saver 中关闭「内嵌工作流」以外会压缩元数据的选项。

### 为什么有些老节点参数显示成 `param_3` 之类？

老工作流可能没有 `widgets_values_named`，而 ComfyUI 的 `widgets_values` 只是没有名字的数组。常见节点（KSampler、Checkpoint、EmptyLatentImage 等）有内置映射；完全未知的第三方节点无法凭空知道每个控件的名字，只能按输入名或序号回退。新版 ComfyUI 保存的工作流通常没有这个问题。

### 子图里的改动能看到吗？

会。工具会比较子图定义中的内部节点参数和 Bypass 状态，并把差异归到对应子图实例节点上；但更深层的嵌套子图仍按实例参数比较，不会无限展开。

### 支持哪些“成品图”？

PNG / JPEG / WebP。GIF、AVIF、HEIC 暂不支持。图片格式按文件签名识别，不只看扩展名。

## 已知边界

- 不加载服务端 `object_info`，所以未内置的第三方节点名称只能显示原始 class 名；参数名依赖工作流里已有的名字信息。
- 纯 API Prompt 没有 UI 坐标，也没有 Bypass 信息；要完整图请使用包含 `workflow` 的图片或 `.json`。
- 当前界面默认比较节点参数与状态，不比较连线来源；如果两边节点 ID 被大量重编号，仍会有“新增/删除”噪音。
- A1111 摘要与完整工作流混合比较时，提示词、调度器等只能按摘要字段近似对齐，界面会显示提示。
- 操作标签会做简单的重叠避让；变更节点特别多时可能仍需要放大查看，但标签可点击定位。
- 这是本地静态页面，不连接 ComfyUI 服务，也不会直接修改你的工作流。

## 隐私

所有文件在浏览器内存中解析，不上传、不写入服务器。导出的 Markdown 由你自己保存。

报告和复制的待办清单包含所导入文件的名称、提示词及参数；对外分享前请自行检查这些内容。仓库不包含个人工作流、生成图片或原始测试截图。
