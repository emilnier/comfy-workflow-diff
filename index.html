QUICK GUIDE

怎么用

  1. 拖入 A 当前和 B 目标：A 是你现在的工作流，B 是你希望改成的目标工作流。既可以是 ComfyUI 导出的 .json，也可以是带元数据的原图。
  2. 直接看操作：每个差异会归为「复制 B 参数 / 改为 Bypass / 启用 / 新增 / 删除」，不再需要自己从参数表推断该做什么。
  3. 点哪看哪：点击左侧节点、图中节点或固定尺寸操作标签，都会打开右侧详情，并自动跳到第一条差异。

低缩放操作层

默认只看变更、不显示连线。缩小后节点边框会看不清，因此会显示固定屏幕尺寸的操作标签，并保留节点名、组名、颜色和纹理。

复制 B 目标值

差异行、右侧参数、A/B 值框、全部参数表和节点标题旁都有复制按钮；也可以复制整份 A→B 待办清单。

图片元数据

ComfyUI 原生 PNG 通常内嵌 workflow 与 prompt，可还原节点布局。Image Saver 的 JPEG/WebP 会把 workflow 写进 EXIF；若只剩 A1111 参数，也能生成摘要图。

节点名称

优先使用你在 ComfyUI 里给节点起的标题，并显示所在组名；数字 ID 只作为辅助定位信息。

图片被转存后可能丢元数据。聊天软件、截图、图床压缩通常会移除 PNG 文本块或 EXIF。请使用 ComfyUI 直接输出的原图；本工具无法从像素反推工作流。
